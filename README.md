# Star Wars App

Este projeto é um aplicativo móvel desenvolvido em **React Native** com **Expo** que consome dados da API pública de Star Wars ([SWAPI](https://swapi.dev/)) e exibe informações detalhadas sobre personagens, naves e filmes do universo de Star Wars.

## Funcionalidades

- **Tela de Personagens**: Exibe uma lista de personagens do universo Star Wars com detalhes como altura, peso, cor dos olhos, cabelo e gênero.
- **Tela de Detalhes do Personagem**: Exibe informações detalhadas sobre um personagem específico, com opções de navegação para ver suas naves e filmes.
- **Tela de Naves e Filmes**: Exibe detalhes sobre as naves e filmes em que o personagem participou.
- **Tema Visual**: O app utiliza um tema visual inspirado no universo de Star Wars, com cores douradas e fundos personalizados.
- **Música Tema**: A música tema de Star Wars toca na tela "Sobre", criando uma experiência imersiva.

## Tecnologias

- **React Native**: Framework para desenvolvimento de apps móveis nativos.
- **Expo**: Plataforma que facilita o desenvolvimento e a publicação de apps React Native.
- **React Navigation**: Biblioteca para navegação entre telas no app.
- **Axios**: Biblioteca para fazer chamadas HTTP à API de Star Wars.
- **Expo Audio**: Usada para tocar a música tema de Star Wars no app.
